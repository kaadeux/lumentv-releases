# Lumen TV — versions publiées

Ce dépôt contient uniquement le fichier d'installation de Lumen TV, un lecteur IPTV pour Android TV / Google TV à usage familial privé.

- `LumenTV.apk` : dernière version.
- `version.json` : utilisé par l'application pour proposer les mises à jour.

L'application ne fournit aucune chaîne ni aucun contenu, et un code d'accès est demandé au premier lancement.
